# 論文執筆ルール

このファイルは、論文草稿を Codex が編集する際に常に参照すべき、全体共通の体裁・構成ルールを整理したものである。

## 適用範囲

- これは論文草稿全体に適用する体裁・構成上の制約として扱う。
- 基本方針は LLNCS / Springer 系のテンプレートに従う。
- 投稿先の正式ガイドラインに明示的な上書きがある場合は、そちらを優先する。
- テンプレート内のダミーの著者名、所属、ORCID、参考文献、定理例は流用しない。

## 論文構成

- 見出しレベルは最大 4 段階までにする。
- 番号を付けるのは第 1・第 2 レベルの見出しまでにする。
- より下位の見出しは原則として無番号とし、必要に応じて run-in heading とする。

## 段落と本文

- 節・小節の最初の段落は字下げしない。
- 表・図・数式などの直後の最初の段落も字下げしない。
- それ以降の段落は字下げする。
- 文字や記号は、可能なら T1 font encoding で問題なく扱えるものを優先する。

## 図表と数式

- 表題は表の上に置く。
- 図のキャプションは図の下に置く。
- 独立表示の数式は中央配置し、別行に置く。
- 線画、図式、スキーマではラスタ画像をできるだけ避ける。
- 可能ならベクター画像を優先する。

## 引用と参考文献

- 引用は角括弧付きの通し番号方式を優先する。
- 複数文献をまとめて引用してよい。
- 参考文献の書式は LNCS / Springer スタイルに合わせる。
- BibTeX を使う場合は `splncs04` を使う。
- Web 参照には必要に応じて `last accessed` 日付を入れる。

## Codex 向け運用ルール

- 論文を編集するときは、投稿先の正式ガイドラインに明示的な上書きがない限り、このルールを維持する。
- 不明点がある場合は、テンプレートの既存記法と周辺の記述に整合する形を優先する。
- 体裁の統一を優先し、不必要な書式変更や大規模な言い換えは避ける。
- 日本語コンパイルはlatexmk -interaction=nonstopmode -halt-on-error [filename.tex]で行う。
